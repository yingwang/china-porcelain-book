# 瓷：中国第一个工业 · 从宋代汝窑到全球贸易网络

> “雨过天青云破处，这般颜色做将来。”  
> 将中国瓷器从单一的“文人雅玩”审美滤镜，重新置回宏阔而严密的“前现代工业史”坐标。

**在线阅读**：[yingwang.github.io/china-porcelain-book](https://yingwang.github.io/china-porcelain-book/)

中国瓷器，绝不仅是帝王案头的孤品或文人赏玩的雅器。自唐末五代越窑秘色、宋代五大名窑（汝、官、哥、定、钧），至明清景德镇御窑厂与民窑千峰翠色的漫长演进，其本质构成了**人类历史上最早、最完整且规模最为庞大的前现代工业制造与全球贸易系统**。

在长达千年的窑火历程中，中国工匠在缺乏现代热力学与化学仪器的条件下，直面并攻克了一系列极其复杂的工业命题：
- **矿物与原料开采**：麻仓土与高岭土的二元配方发现，使瓷胎在 1300℃ 高温下保持形态不塌；
- **热工流体与窑炉演化**：从顺应山势的百米龙窑、北方聚热的馒头窑，到景德镇汇聚大成的蛋形镇窑；
- **微观物理与釉色化学**：铁、铜、钴离子在极度狭窄的还原焰温区内的价态控制（天青、郎窑红、青花与釉里红）；
- **七十二道精细分工**：“共计一坯之力，过手七十二，方克成器”，开创了比工业革命早数百年的工序流水线；
- **严苛品控与标准化**：官窑“十选其一，余者尽毁”的落选瓷打碎掩埋制度，与外销克拉克瓷的标准化开光模块；
- **水陆物流与全球贸易**：依托昌江入鄱阳湖、顺长江出东海，成为十七世纪大航海时代跨越欧亚大陆的硬通货贸易品；
- **工艺保密与逆向工程**：从殷弘绪神父的密信刺探，到迈森（Meissen）与韦奇伍德（Wedgwood）的欧洲逆向工程突破；
- **当代前沿与 AI 赋能**：从氧化锆生物陶瓷、航天耐烧蚀涂层，延伸至大模型时代的陶瓷微观痕迹无损断代与视觉特征识别。

本书将瓷器重新放回它最深沉、最坚固的基底：**工业文明与物质美学的交融之巅**。
