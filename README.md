# 瓷：中国第一个工业

> 将中国瓷器从“工艺美术”的审美滤镜，重新置回宏阔的“工业史”坐标。

**在线阅读**：[yingwang.github.io/china-porcelain-book](https://yingwang.github.io/china-porcelain-book/)

景德镇自唐末至清末历经千年的窑火与生产，本质上构成了人类历史上最早、最完整且规模最为庞大的前现代工业系统。它所直面并解决的系统命题（原料开采、热工控制、器型标准化、严苛品控、精细分工、水陆物流、全球贸易网络、知识沉淀与防范逆向工程），与当代先进制造体系所应对的工程挑战在底层逻辑上一脉相承。

本书将瓷器重新放回它最深沉、最真实的基底：**工业**。

## 引用与考据

本书所有涉及具体年代、产销规模、人物生平与历史事件的论述，均依托严谨可溯的公开文献，包括田野考古发掘报告、博物馆馆藏档案、权威学术期刊专论与地方志典籍。各章末尾均设有独立的“参考文献”小节，注释编号按序编排。

凡未掌握确凿一手出处的细节，宁可存疑阙如，亦绝不以文学虚构替代史实。阶段性存疑之处明确标注备忘。全书恪守实证底线：**凡有叙述皆有据可查，凡涉定论皆严谨审慎。**
